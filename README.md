# 📖 About The Project

The Mopyane Wedding Website is a modern digital wedding invitation platform developed to celebrate and professionally present a family wedding event online.

The website was built to provide:

* A memorable digital invitation experience
* Elegant presentation of wedding information
* Event celebration through modern web design
* Easy access to event details for guests
* Beautiful visual storytelling

This project combines creativity, frontend development, and user experience design to create a professional and emotionally engaging website.
